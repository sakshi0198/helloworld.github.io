# JavaScript Number Operations

## About the Project

This project performs different mathematical operations on a given number using JavaScript.

The program demonstrates the use of variables, loops, conditional statements, arithmetic operators, and console output.

---

## Operations Performed

- Find the sum of first n numbers
- Print the multiplication table of n
- Check whether a number is prime
- Print all factors of the number
- Find the sum of digits
- Check whether the number is an Armstrong number

## How to Run

1. Open the project folder.
2. Open **index.html** in your browser.
3. Press **F12**.
4. Open the **Console** tab to view the output.
