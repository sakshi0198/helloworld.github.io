# JavaScript Number Operations

## About

This project is part of my JavaScript practice assignment.

The program performs different operations on a number entered by the user.

## Operations

- Sum of first n numbers
- Multiplication table
- Prime number check
- Print factors
- Sum of digits
- Armstrong number check

## Technologies

- HTML
- CSS
- JavaScript

## How to Run

1. Open `index.html`.
2. Enter the numbers when the prompt appears.
3. Open the browser console (F12 → Console) to see the output.

## What I Learned

While doing this assignment, I practiced using:

- Variables
- for loops
- while loops
- if-else statements
- Functions
- prompt()
- console.log()

Initially I used fixed numbers, but after reviewing my work I changed the program to take user input using `prompt()`. I also separated each task into its own function, which made the code easier to understand and test.
