# Tailwind Hero Landing Page

## Project

This project is a simple landing page created using **HTML** and **Tailwind CSS**.

The page is based on a modern workspace platform design. It contains a sticky navigation bar, hero section, dashboard preview, floating cards, and a fixed chat button.

The purpose of this assignment was to practice using Tailwind CSS utility classes, especially different positioning utilities such as **relative**, **absolute**, **sticky**, and **fixed**.

---

## Technologies Used

- HTML5
- Tailwind CSS (CDN)

---

## Features

- Sticky navigation bar
- Hero section with gradient background
- Large heading and description
- Two call-to-action buttons
- Dashboard preview image
- Floating information cards
- Fixed chat widget
- Responsive layout using Tailwind utilities

---

- Flexbox

- Absolute positioning
- Sticky navigation
- Fixed positioning
- Spacing utilities
- Typography utilities
- Background and color utilities

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open **index.html** in any web browser.
4. Internet connection is required because Tailwind CSS is loaded using the CDN.
