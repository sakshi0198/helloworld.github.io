# Responsive Food Delivery Landing Page (OmniFood Demo)

## Project Overview

This project is a responsive Food Delivery landing page created using HTML and CSS. The design is inspired by the OmniFood website. The main objective of this assignment was to practice building responsive web pages using Flexbox, Grid, media queries, and proper HTML structure.

The website is designed as a single-page landing page and works on desktop, tablet, and mobile devices.

---

## Features

- Responsive navigation bar
- Hero section with background image and overlay
- Call-to-action buttons
- How It Works section
- Our Cities section
- Customer Testimonials section
- Pricing Plans section
- Footer with navigation links and social icons
- CSS-only responsive hamburger menu for mobile
- Responsive layout using Flexbox and CSS Grid

## Responsive Design

The website is responsive for different screen sizes.

### Desktop
- Full navigation
- Multi-column layout
- Large images and headings

### Tablet
- Sections adjust into two columns
- Images resize automatically
- Navigation spacing is reduced

### Mobile
- Single-column layout
- CSS-only hamburger menu
- Responsive buttons
- Responsive typography
- No horizontal scrolling

## What I Learned

While working on this project, I learned how to:

- Create responsive layouts using Flexbox and Grid.
- Use media queries for different screen sizes.
- Build reusable sections using HTML and CSS.
- Add overlays on background images.
- Design responsive cards.
- Create a simple CSS-only hamburger menu.
- Organize CSS in a better way.

---

## Challenges Faced

Some parts of this project took extra time, especially:

- Making every section responsive.
- Aligning cards properly.
- Adjusting spacing on smaller screens.
- Making the navigation work well on mobile.
- Preventing horizontal scrolling.

I solved these by testing the page on different screen sizes and updating the CSS until the layout looked correct.
