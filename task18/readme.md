# Greeting and Color Boxes

## About

This is a simple JavaScript practice project.

The page starts with the text **Hello** at the top. A user can enter their name and click the **Greet** button to change the heading.

There are also four boxes named Red, Blue, Green, and Yellow. Clicking on a box changes its background to the corresponding color.

## Features

- Greeting message changes after clicking the button.
- Four color boxes.
- Clicking a box changes its background color.
- Simple layout using HTML and CSS.
- DOM manipulation using JavaScript.

---

## How to Run

1. Open the project folder.
2. Open `index.html` in your browser.
3. Enter your name.
4. Click the **Greet** button.
5. Click on any color box to change its background color.
