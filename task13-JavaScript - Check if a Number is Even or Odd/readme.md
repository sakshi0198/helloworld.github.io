# Even or Odd Checker

## About the Project

This is a simple JavaScript project that checks whether a number is even or odd using an **if-else statement**.

The project uses four predefined variables and displays the result in the browser console.

---

## Technologies Used

- HTML5
- CSS3
- JavaScript

---

## Project Structure

```
Even-Odd-Checker/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

---

## How It Works

The program:

- Creates four number variables.
- Uses the modulus operator (`%`) to check whether each number is even or odd.
- Displays the result using `console.log()`.

---

## Sample Output

```
The number 5 is odd.
The number 10 is even.
The number 17 is odd.
The number 24 is even.
```

---

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Press **F12** and open the **Console** tab to view the output.
